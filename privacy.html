This Privacy Policy explains how Grand Vision Heavy Industry Limited ("we", "us") handles information when you play Fruit Slash Party (the "Game") inside TikTok.

1. Local Game Data

The game is single-player. Your best score and any earned continue tokens are stored on this device only. We do not create a game account, link progress to your TikTok identity, synchronize progress, operate a leaderboard, or collect profile information. Clearing mini-game data or changing devices may remove local progress.

2. TikTok Platform Capabilities

The Game does not call TikTok login or authorization APIs, create a Game account, request profile information, or collect identity data. It uses TikTok's profile-sidebar and home-screen shortcut mission APIs and may use TikTok's rewarded video API. TikTok processes platform-account, mission, and advertising information under TikTok's own policies.

3. Rewarded Advertising

The Game includes an optional, player-initiated TikTok rewarded video. If the player watches it to completion, the Game grants one continue for the current run. The Game does not show forced or interstitial advertisements. TikTok may process device and advertising interaction data to serve and measure the video under TikTok's policies.

4. Purchases and Other Features

The Game has no in-app purchases, game shop, cross-device sync, social leaderboard, or user profile. It uses TikTok's profile-sidebar revisit and home-screen shortcut capabilities for mission access.

5. Children

The Game is a casual arcade game and is not directed at children under 13. We do not knowingly collect personal information from children. Contact us if you believe a child has provided personal information.

6. Data Removal and Retention

Local scores and continue tokens can be removed by clearing the mini-game data. The Game does not transmit them to a game backend. TikTok processes information needed to operate its platform mission and advertising features under TikTok's own policies.

7. Security

The Game package contains no TikTok client secret, OAuth code exchange, or game backend. Local scores and continue tokens remain on the device. We do not sell personal information.

8. Changes

We may update this Policy; the date above will change if the policy changes.
